# v1.4 冗余模块合并报告

## 合并策略

v1.4 不删除功能、不删除路由、不删除接口，只通过菜单聚合和 Tab 合并降低可见复杂度。

| 模块 | 当前问题 | 处理方式 | 是否保留路由 | 是否保留接口 | 是否影响测试 |
| --- | --- | --- | --- | --- | --- |
| Dashboard 与 AgentOps | 都展示运行相关指标 | 首页只保留业务摘要，AgentOps 放入运行观测 | 是 | 是 | 不影响 |
| Agent Eval 与 RAG Quality | 都出现质量指标 | Agent Eval 展示整体质量，RAG Quality 展示检索质量 | 是 | 是 | 不影响 |
| Diagnostics 与 AgentOps | 都用于排障 | Diagnostics 作为运行观测的失败诊断 Tab | 是 | 是 | 不影响 |
| Tool Registry / Approval / Schema / Manifest | 工具能力入口分散 | 合并到平台治理设置的工具管理和审批策略 | 是 | 是 | 不影响 |
| Case Knowledge 与 Memory Center | 都属于知识辅助 | 合并到知识增强与质量，不同 Tab 展示 | 是 | 是 | 不影响 |
| 演示模式配置 | 属于演示边界说明 | 不做独立菜单，只在首页和配置中心说明 | 是 | 是 | 不影响 |
| 最终验收与交付包 | 属于答辩前自检 | 保留在 scripts、docs、delivery 中 | 不作为业务路由 | 是 | 不影响 |

## 明确不新增的后台业务模块

本阶段没有新增“演示与交付检查”“服务状态中心”“最终验收中心”“一键启动页面”“数据库备份恢复页面”“交付包检查页面”等后台菜单。相关能力继续由命令行脚本和交付文档承载。
