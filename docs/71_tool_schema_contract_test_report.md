# 工具结构校验与契约测试报告

## 测试目标

v1.2 对工具注册中心中的每个本地工具进行结构校验和契约测试，确认输入输出结构不是展示占位，而是可以被脚本验证的本地契约。

## 校验范围

- 工具名称存在。
- 输入结构为合法 JSON，并包含类型。
- 输出结构为合法 JSON，并包含类型。
- 风险等级在允许范围内。
- 审批要求为布尔值。
- 启用状态为布尔值。

## 契约测试方式

系统为每个默认工具生成模拟输入和模拟输出，只做本地结构匹配，不调用外部工具，不改变业务数据。测试接口为：

- `GET /admin/ai/tool/schema/validate`
- `POST /admin/ai/tool/schema/test`
- `GET /admin/ai/tool/schema/report`

脚本 `scripts/e-review-tool-schema-check.ps1` 用于自动验收，成功输出 `TOOL_SCHEMA_CHECK_PASS`。

## 当前结论

v1.2 的工具结构校验和契约测试用于证明系统具备工具协议治理的基础能力。该能力仍是本地实验增强，不代表生产级工具平台。
