# v1.2 智能体协议与检索质量增强计划

## 当前基础

v1.1.1 已完成中文化产品体验，后台具备 AI 工作台、真实用户端评价闭环、工具注册中心、工具审批、记忆中心、安全护栏、智能体运维、智能体注册中心和检索质量概览。v1.0.4 仍作为稳定答辩主线，v1.2 只作为平台能力实验增强线。

## 剩余差距

- 工具注册已有页面展示，但缺少可导出的工具协议清单。
- 工具输入输出结构已有定义，但缺少统一校验和契约测试。
- 案例知识库已有本地召回，但缺少关键词、风险类型、混合检索和轻量 TF-IDF 的横向对比。
- 检索质量已有脚本，但缺少失败样本、低分样本和推荐策略表现分析。
- 智能体运维已有摘要，但趋势、最近运行和失败 Top 统计还不完整。
- 工具审批已有批准/拒绝演示，但状态流和时间线不够清晰。

## v1.2 补强动作

- 新增工具协议清单（Tool Manifest）、OpenAPI 风格描述和本地 MCP 风格描述导出。
- 新增工具结构校验、契约测试和工具执行日志对齐检查。
- 新增案例知识库 v2 检索接口，支持关键词检索、风险类型检索、混合检索和本地 TF-IDF 检索。
- 扩展黄金 RAG 查询集到 40 条，输出 v1.2 检索质量报告。
- 扩展智能体运维趋势、最近运行、失败 Top、工具失败 Top、本地回退分布和质量趋势。
- 扩展工具审批状态流：待审批、已批准、已拒绝、已执行、已复核、已过期。

## 边界

- 不接真实支付、真实物流或真实退款。
- 不接外部 MCP 服务，不声明已经接入真实 MCP。
- 不接 Qdrant 或外部向量数据库，不下载外部模型。
- 不替代 v1.0.4 稳定答辩主线。
- 不破坏 v1.1.1 中文展示。
- 所有新增能力必须能通过脚本验收。
