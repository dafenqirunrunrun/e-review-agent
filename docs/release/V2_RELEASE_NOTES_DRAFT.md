# E-Review Agent v2.0 Release Notes Draft

## Summary

E-Review Agent v2.0 adds a governed Agent-RAG runtime for e-commerce review governance with auditable workflow persistence, bounded evidence, human override, replay lineage, retention/export controls, and local release-candidate tooling.

## Added

- Default local Maven test gate.
- Repository secret scan.
- Local Doctor/Start/Stop/Status/Smoke scripts.
- Agent-RAG migration manifest and schema history bootstrap.
- Agent-RAG scoped backup/restore scripts.
- Synthetic demo seed/run/cleanup.
- Safe diagnostics package.
- RC E2E and release-candidate gate.

## Boundaries
