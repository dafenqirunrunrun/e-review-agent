# 11 Pilot 60设计

本文件只设计配额，不创建正式样本。

## 1. 推荐配额

| 模块 | 数量 | 目的 |
|---|---:|---|
| 商品质量/安全边界 | 8 | 验证质量与安全是否需拆分 |
| 虚假宣传/描述不符 | 8 | 验证欺骗与不一致边界 |
| 售后/客服 | 8 | 验证处置结果与服务体验边界 |
| 物流/图文冲突/价格 | 8 | 覆盖其他业务场景 |
| 多风险与高风险 | 8 | 验证主次标签和升级规则 |
| 正常/低风险 | 6 | 控制误报 |
| 信息不足/无相关证据 | 6 | 控制过度作答和伪Citation |
| 安全治理 | 4 | 注入、PII、越权、伪Citation |
| 鲁棒性 | 4 | 反讽、错别字、五星投诉、中英混合 |
| 合计 | 60 | — |

具体风险类别必须先与仓库枚举对齐。

## 2. 来源分布

Pilot不应全部来自同一来源。建议：

- 真实授权或公开许可：不少于20；
- 人工改写/场景设计：不少于20；
- 知识库受控合成：不超过15；
- 安全与鲁棒性专门设计：约5–10。

## 3. 双标

60条全部双人独立标注，不显示模型预测。

## 4. Pilot需要回答的问题

- 风险本体是否过细或重叠；
- 严重程度规则能否稳定使用；
- Chunk级Evidence是否可操作；
- 无风险、信息不足、无证据能否区分；
- 语义去重阈值是否误删困难样本；
- Schema是否遗漏关键字段；
- 标注平均时长；
- 分歧主要集中在哪些类别。

## 5. 升级到v1.0门禁

- P0/P1为0；
- 关键标签κ≥0.75；
- 未仲裁分歧为0；
- Gold Evidence可解析率100%；
- 去重人工复核流程可执行；
- 收集与标注时间成本可接受；
- 至少完成一次盲标和仲裁全流程。

不满足时继续Pilot，不得直接收500条。
