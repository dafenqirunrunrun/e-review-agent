# v1.2.1 中期答辩演示路线

## 演示定位

本路线用于 v1.2.1-quality-and-browser-verification 的中期答辩展示。演示重点不是新增业务功能，而是说明 E-Review Agent 已经从“评论分析功能”扩展为“可治理、可追踪、可评估、可运维”的 AI Agent 评论治理原型。

本路线继续遵守当前系统边界：不接真实支付、不接真实物流、不接 Qdrant、不接外部 MCP 服务、不宣称生产级大模型部署。

## 启动顺序

1. 启动 MySQL，确认 `litemall` 数据库可访问。
2. 启动 AI 服务：`http://127.0.0.1:8008`。
3. 启动 wx-api：`http://localhost:8080`。
4. 启动 admin-api：`http://localhost:8083`。
5. 启动 H5 用户端：`http://localhost:6255`。
6. 启动后台管理端：`http://localhost:9527`。
7. 执行 `scripts/e-review-v12-acceptance.ps1`，确认 `V12_ACCEPTANCE_PASS`。

## 主线一：前后台评论治理闭环

1. 打开 H5 用户端首页。
   - 展示点：商品浏览入口已经接入真实 litemall 用户端。
   - 讲解词：系统不是孤立后台，而是接入了电商前台浏览、下单、确认收货和评价流程。

2. 进入商品详情并完成演示下单。
   - 展示点：保留原商城链路，支付和发货使用答辩演示模式。
   - 讲解词：为了避免真实支付和物流依赖，系统只推进演示订单状态，不改真实支付回调。

3. 提交图文评价。
   - 展示点：评价写入真实商品评价表，后续可被后台巡检扫描。
   - 讲解词：这一步把用户真实评价纳入 AI Agent 治理对象，而不是只依赖后台手工输入。

4. 打开后台 AI 工作台总览。
   - 展示点：Dashboard 展示分析数量、风险任务和处理状态。
   - 讲解词：总览页用于答辩时快速说明系统的整体运行态势。

5. 进入 Agent 巡检中心并执行立即巡检。
   - 展示点：巡检任务扫描 demo 评论和真实商品评价。
   - 讲解词：Agent 负责发现待分析评论、调用本地 AI 服务、落库分析结果并生成风险任务。

6. 打开风险评论中心。
   - 展示点：高风险评论生成任务，风险等级和建议清晰展示。
   - 讲解词：风险中心把模型输出转换为运营可处理的任务，不直接替代人工决策。

7. 打开运营处理中心。
   - 展示点：运营人员采纳建议、记录处理结果并闭环。
   - 讲解词：系统最终目标是“发现风险、辅助决策、人工确认、形成记录”的闭环治理。

## 主线二：v1.2 Agent 平台能力

1. 打开工具注册中心。
   - 展示点：工具列表、风险等级、审批要求和启用状态。
   - 讲解词：工具不再只是页面按钮，而是可以被治理和追踪的 Agent 能力单元。

2. 展示工具协议清单。
   - 展示点：本地工具协议清单、OpenAPI 风格描述、本地 MCP 风格描述。
   - 讲解词：这里展示的是本地协议描述能力，不代表已接入外部 MCP 服务。

3. 展示工具结构校验。
   - 展示点：工具输入输出结构校验、契约测试和报告。
   - 讲解词：系统用脚本检查工具结构，避免只停留在静态展示。

4. 展示审批时间线。
   - 展示点：审批状态从待审批、已批准、已执行到已复核。
   - 讲解词：高风险工具需要人工确认，系统保留可追踪的审批路径。

5. 打开案例知识库。
   - 展示点：v2 检索支持 keyword、risk_type、hybrid、tfidf 策略。
   - 讲解词：案例知识库用于给风险判断提供相似案例和处理参考。

6. 打开 RAG 质量评估。
   - 展示点：v1.2 当前基准为 40 条黄金 RAG 查询。
   - 讲解词：旧 20 条报告已标记为历史报告，当前 v1.2 以 40 条样本报告为准。

7. 打开智能体运维。
   - 展示点：最近运行、失败 Top、回退分布、RAG 趋势和质量趋势。
   - 讲解词：Agent 系统需要可观测性，运维趋势用于说明稳定性和后续优化方向。

8. 打开安全护栏、记忆中心和智能体注册中心。
   - 展示点：风险拦截、记忆画像、智能体卡片。
   - 讲解词：这些能力说明系统具备进一步产品化的架构基础。

## 推荐截图顺序

1. H5 用户端首页和商品详情。
2. 用户端提交评价页。
3. AI 工作台总览。
4. Agent 巡检中心立即巡检结果。
5. 风险评论中心任务详情。
6. 运营处理中心处理记录。
7. 工具协议清单。
8. OpenAPI 风格描述。
9. 本地 MCP 风格描述。
10. 工具结构校验结果。
11. 审批时间线。
12. 案例知识库 v2 检索。
13. RAG 质量评估 40 条样本。
14. 智能体运维趋势。

## 兜底路线

如果现场前台订单链路受登录或本地服务影响，可切换后台 Demo 评论提交作为备用路径：

1. 后台登录。
2. 进入模拟用户图文评论提交。
3. 提交风险评论。
4. 进入 Agent 巡检中心立即巡检。
5. 进入风险中心和运营中心展示治理闭环。
6. 返回 Dashboard 展示数据变化。

该备用路径只用于现场兜底，不替代真实用户端闭环主路径。
