# v2.2 Real Model Limitations

The v2.2 branch is an experimental qualification branch. It does not claim
production readiness.

Still out of scope unless separately verified:

- high availability
- distributed vector databases
- production concurrency
- million-scale knowledge base operation
- real payment or logistics integration
- model fine-tuning quality
- cloud LLM API quality

Current real-model blockers remain active until official assets, runtime,
quality, E2E and soak all pass:

REAL_LLM_QUALITY_NOT_VERIFIED
