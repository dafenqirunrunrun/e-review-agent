# 智能体运维设计

## 目标

智能体运维看板把诊断页面升级为本地可靠性、质量、策略和回退信号的汇总视图，用于演示前检查与答辩时说明系统稳定性。

## 指标范围

- 今日运行数。
- 成功率。
- 平均耗时。
- 近似 P95 耗时。
- 回退率。
- 安全护栏阻断数。
- 工具失败次数。
- 重放次数。
- 待审批工具数。
- 记忆更新数。
- 案例检索命中率。
- 质量评分。
- 最近运行趋势。
- 服务目标状态。

## 服务目标

默认演示目标如下：

- 成功率不低于 95%。
- 平均耗时不超过 3000 毫秒。
- 回退率不超过 50%。
- 安全护栏阻断数用于可观测展示，不单独作为失败条件。

## 接口范围

- `GET /admin/ai/agentops/summary`
- `GET /admin/ai/agentops/trends`
- `GET /admin/ai/agentops/slo`

## 边界

智能体运维是本地实验视图，服务于毕业设计演示、排练和论文说明，不等同于生产监控平台。
