# 记忆中心设计

## 目标

记忆中心提供轻量级长期风险画像，用于解释某个商品、用户、类目或风险类型是否存在重复问题。它服务于答辩展示和运营辅助，不声明生产级个性化推荐能力。

## 画像维度

当前支持四类画像：

- 商品画像。
- 用户画像。
- 类目画像。
- 风险类型画像。

画像字段包括对象类型、对象编号、画像摘要、风险次数、正向次数、负向次数、重复问题标签和最近事件时间。

## 事件来源

记忆事件来自 AI 分析结果、风险任务和运营处理记录。事件包含来源类型、来源编号、事件类型、事件摘要、风险等级和证据内容。

## 当前实现

当前服务从 `litemall_review_ai_analysis` 与 `litemall_ai_review_risk_task` 构建本地画像，不依赖外部向量库。这样可以保证 v1.1 实验能力不影响 v1.0.4 顾客评价闭环。

## 接口范围

- `GET /admin/ai/memory/profile/list`
- `GET /admin/ai/memory/profile/detail`
- `POST /admin/ai/memory/rebuild`

## 演示验收

当 H5 用户端提交真实评价并被智能体分析后，记忆中心应能看到相关商品或风险类型画像变化。展示时应强调“基于证据的本地画像”，不要描述为生产级用户画像系统。
