# v1.2.1 浏览器人工验收报告

## 验收目标

本报告记录 v1.2.1-quality-and-browser-verification 阶段的浏览器人工点击检查。检查目标是确认 v1.2 新增的 Agent 平台能力可以在后台真实页面中打开、点击、查看，并与自动化验收结果保持一致。

## 检查环境

| 项目 | 地址 |
| --- | --- |
| 后台管理端 | `http://localhost:9527` |
| admin-api | `http://localhost:8083` |
| AI 服务 | `http://127.0.0.1:8008` |
| H5 用户端 | `http://localhost:6255` |
| wx-api | `http://localhost:8080` |

检查日期：2026-06-30

检查方式：

- 使用系统 Chrome 独立临时用户数据目录打开后台管理端。
- 通过管理员登录 token 设置后台 Cookie，再在真实 Chrome 页面中逐路由导航和点击按钮。
- 检查过程不修改业务代码、不修改数据库结构、不移动 tag。
- Codex 内置浏览器连接受本机用户目录 Node ES module 配置影响无法启动，因此本轮使用系统 Chrome 远程调试实例完成真实页面点击检查。
