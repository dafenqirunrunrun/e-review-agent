# 46 最终答辩 PPT 大纲

## 定位

PPT 主线应围绕“电商图文评论智能治理系统”展开，而不是围绕底层商城来源展开。展示重点是 E-Review Agent 如何把用户端真实评价、后台智能体巡检、风险任务和运营处理连接成可演示、可追踪、可测试的闭环。

## 推荐结构

1. 项目背景与问题：电商评论治理需要及时识别负向、售后、图文冲突和低置信度风险。
2. 系统目标：构建前后台一体化的评论智能治理原型。
3. 总体架构：H5 用户端、Spring Boot 后台、Vue 管理端、FastAPI AI 服务和 MySQL。
4. 顾客评价闭环：浏览商品、下单、演示支付、演示发货、确认收货、发布评价。
5. 智能体治理闭环：巡检真实评价、分析落库、生成风险任务、运营处理、Dashboard 更新。
6. AI 评论分析：情感、置信度、风险等级、证据和运营建议。
7. 风险评论中心：高风险任务集中管理。
8. 运营处理中心：人工采纳、转交、回复和关闭。
9. 执行追踪：运行步骤、状态快照和重放对比。
10. 案例知识库：本地案例检索增强和证据复用。
11. 评估中心：黄金样本、诊断、失败分组和质量指标。
12. 测试与验收：构建、冒烟、顾客闭环、完整 UI 流程和最终验收。
13. 创新点：真实业务闭环、自动巡检、人机协同、可观测智能体、质量评估。
14. 边界与展望：真实支付、物流、退款、图片上传、分布式巡检和外部模型是后续方向。
